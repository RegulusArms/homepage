BECAUSE COMPUTERS ARE WEAPONS

EVERY COMPUTER IS A WEAPON.
WE JUST MAKE SURE YOURS IS POINTED THE RIGHT WAY.

An arms company makes tools that let regular people defend what's theirs. In 2026, most of what's yours lives on a hard drive: your photos, your records, your messages, your business. The computer is where the fight actually happens.

Strong encryption was literally classified as a munition by the US government in the 90s, and you needed an export license to ship it overseas. People printed cryptography source code in books and on t-shirts to make the point that code is speech. We think they were right on both counts: code is speech, and code is arms.

So we build software the same way we build everything else: in-house, open, and meant to be owned by the person using it. No subscriptions, no telemetry, no cloud account. Everything is MIT licensed, so you can read every line, build it yourself, and keep it forever.

Why open source? Because you shouldn't have to trust us. A security tool you can't inspect is just a promise. Read the source, compile it yourself, and verify.

OUR ARSENAL

🔒 PNP — ENCRYPTION THAT SURVIVES P = NP

C11, libc onlyDebian / Ubuntu / MintMIT

Almost all encryption in use today is safe only because some math problems are hard to solve. If someone ever proves P = NP, or quantum computers get good enough, a lot of that protection could fall apart overnight.

pnp is a command-line tool that encrypts files with a one-time pad: a key of truly random bytes, as long as the file, pulled from your machine's hardware random number generators and combined with the file using XOR. A one-time pad doesn't rely on anything being hard to compute, so no faster computer and no clever new algorithm can break it. It's the only encryption that's provably unbreakable.

The catch: the key is as big as the file, you can never reuse it, and if you lose it, the file is gone. pnp helps with that: it can write keys straight to a USB stick, split a key into shares that must all be present, or lock a key behind a passphrase.

pnp photo.jpg # writes photo.jpg.pnp + photo.jpg.pnp.key pnp -d photo.jpg.pnp # decrypts it again pnp --sources # shows which hardware random sources you have

📁 KESTREL EXPLORER — A FILE MANAGER THAT DOES THE JOB

C++ / Qt 6Ubuntu / Kubuntu / MintMIT

Why do Linux users still need five separate utilities and a terminal to do normal filesystem work? Kestrel is our answer: a file manager for Ubuntu and Linux Mint that puts the jobs you'd usually do in a terminal right in the window.

  • Archives: 7z, zip, rar, zpaq and every tar format, with passwords, split volumes, and a preview of the exact command it'll run.
  • Checksums: make and verify MD5/SHA files, so you know a download wasn't tampered with.
  • Metadata: view and strip EXIF/XMP data (like the GPS location baked into your photos) before you post them.
  • Drive imaging: back up a whole drive byte for byte, compressed and encrypted, and mount disk images like a USB stick.
  • Secure deletion: shred files so they can't be recovered (with BleachBit installed).
  • Admin only when needed: retry a failed copy as administrator instead of running your file manager as root.
