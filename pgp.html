HOW TO USE IT

1. Import the key

Download pgp.asc (or copy the block above into a file) and import it with GnuPG:

gpg --import pgp.asc

Or grab it straight from the site in one go:

curl -s https://regulusarms.com/pgp.asc | gpg --import

2. Verify the fingerprint

Before you trust the key, make sure the fingerprint matches the one shown on this page:

gpg --fingerprint ross@regulusarms.com

If it doesn't match F5F6 5F11 212A 834C F7B2 693C 8228 144A 4A05 AC6F exactly, don't use it and let us know.

3. Send us an encrypted message

Encrypt a file so only we can read it:

gpg --encrypt --armor --recipient ross@regulusarms.com message.txt

This creates message.txt.asc. Attach it to an email or paste its contents into the body and send it to ross@regulusarms.com.

You can also send it to our backup address, RegulusArms@cock.li — it's checked at least once a week, so expect slower replies. Encrypt to the same key as above (keep --recipient ross@regulusarms.com); only the address you send to changes.

Want a reply you can read? Include your own public key with your message:

gpg --export --armor you@example.com > mykey.asc

4. Verify something we signed

If we send you a signed message or file, check that it really came from us:

gpg --verify file.txt.asc

Look for Good signature from "RegulusArms <ross@regulusarms.com>". Anything else means the file was altered or wasn't signed by us.

Not a command-line person?

  • Windows: Gpg4win (Kleopatra)
  • macOS: GPG Suite
  • Email: Thunderbird has OpenPGP built in — import the key under Account Settings → End-To-End Encryption.
  • Android: OpenKeychain
Heads up: PGP encrypts the message body and attachments, but not the email subject line, sender, or recipient. Keep anything sensitive out of the subject.
